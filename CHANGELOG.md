# Changelog

## 0.1.1 (2026-10-20)

- The microphone button now sits in the middle of single-line text fields. In search boxes with a frame around the input, it used to sit too low, sometimes past the bottom edge.

## 0.1.0 (2026-10-12)

- First release for Chrome and Firefox.
- Website workflows: tells TypeWhisper which page is open in the active tab.
- `⌥⇧D` (Alt+Shift+D) starts or stops a dictation.
- **Dictate with TypeWhisper** in the context menu of text fields.
- Optional microphone button in the focused text field.
